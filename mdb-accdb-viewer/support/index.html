MDB ACCDB Viewer Support

Read Microsoft Access database tables, explore records and export data on your device.

Open a database

Choose Choose Database…, then select an MDB or ACCDB file. On Mac you can also drag a file onto the welcome screen. Select a table to view its rows, columns and relationships.

Search, query and export

Use table search and Filter & Sort to narrow records. Search Database on Mac or Search All Tables on iOS searches across tables. SQL Worksheet supports read-only queries, including joins, using a local SQLite snapshot.

On Mac, use Export in the toolbar. On iPhone and iPad, open Database Actions. Available database outputs include Excel, SQLite, SQL and ZIP archives of CSV/TSV tables. Choose where to save using the system file interface.

A file will not open

Use an unencrypted file containing local tables. Modern password-protected or encrypted ACCDB files are not supported. Forms, reports, macros, VBA, linked tables and Access saved queries are outside scope. MDE and ACCDE support is limited to readable tables. Some file versions, newer field types or damaged files may not be readable.

Large files and storage

Opening a table for the first time builds a local index and can take time and disk space. The first SQL query builds a separate local snapshot. Table caches remain for reuse and are not automatically pruned. Removing a recent-file entry does not remove cached records. Contact us for help removing local cache data.

Attachments and long text

Use the row inspector to inspect long text and supported attachments. Embedded payloads must be exported separately from whole-database exports. Excel cells are limited to 32,767 characters, so longer text is truncated in XLSX exports.

Contact support

Email admin@yenpi.com with your device, operating system, app version, file extension and the error message or steps to reproduce. Please avoid sending private databases or passwords. A small anonymized example can help investigate compatibility.
