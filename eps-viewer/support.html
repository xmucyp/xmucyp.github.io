EPS Viewer: Opener & Converter

Support

Open vector artwork, inspect its details and export the format you need on Mac, iPhone and iPad.

Open a document

On Mac, use Open File… or drag a document into the app. On iPhone or iPad, select a document in the document browser or open it from Files.

Supported inputs: EPS (.eps, .epsf, .epsi), PostScript (.ps), legacy PostScript-based or PDF-compatible Illustrator (.ai), PDF, SVG, XPS and OpenXPS.

On Mac, choose Try a sample… in the Welcome window to explore the included artwork.

Export or batch convert

Choose Export… from an open document, select a format and page selection, then save or export the result. Available formats are PDF, SVG, EPS, PostScript, PNG, JPEG, TIFF and HEIC when the device has an encoder. For transparent images, choose PNG or TIFF.

On Mac, open Batch Convert… from Welcome or the File menu. On iPhone and iPad, open the document View menu and choose Batch Convert…. Add supported files, choose output options and a destination folder.

EMF and DXF export are not supported. Viewing .ai files does not imply export to the native Illustrator format.

Free files and Pro

Two different files per device calendar day can be opened or converted free with every tool. The app identifies files by their content, so reopening a file that day is free. Bundled samples are always free. Batch conversions share the same allowance.

Pro permits any number of files. Choose a weekly auto-renewable subscription or a one-time lifetime purchase. Current prices appear in the app before purchase. Use Restore Purchases in the upgrade screen with the Apple Account used to purchase. Manage or cancel subscriptions in your App Store account settings.

Troubleshooting

  • If a file cannot open, confirm that it contains a supported format; renaming its extension does not convert it. Illustrator files need legacy PostScript or PDF-compatible contents.
  • If artwork is clipped or surrounded by excess space, use the bounding box check and save a corrected copy.
  • If a sample shows Locked in the Mac title bar, it is a read-only resource inside the app. You can still view and export it.
  • If a free-file limit appears, reopen one of today's files, try a bundled sample on Mac, wait until the next device calendar day, or unlock Pro.
  • If HEIC does not appear, use PNG, JPEG or TIFF instead.
