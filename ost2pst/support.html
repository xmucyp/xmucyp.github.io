OST to PST

Support

Need help with OST to PST? Email admin@yenpi.com.

Open a mailbox

Choose Open File and select an OST or PST file. On Mac, you can also drag a file onto the start screen. On iPhone and iPad, select your mailbox through Files.

Preview messages and attachments

Browse the folder list or search for a folder by name. Select a folder to see its item preview, then open a message to read its available body and headers. Quick Look can preview supported file attachments. On Mac, supported file attachments can also be saved from the message reader.

A folder preview may show only some of its items. Conversion includes the mailbox items, rather than only the preview rows.

Create a PST copy

Choose Convert to PST. On Mac, select the output location in the save dialog. On iPhone and iPad, keep the app open while it writes the PST, then export the completed file through Files. Your source mailbox stays unchanged.

Check the output

Enable Verify every item after converting to compare the output with your source. Review any differences reported by the app before using the new file.

If conversion stops

Check that the source file is accessible and that there is enough storage for the output. On iPhone and iPad, keep the app in the foreground while converting. If the system suspends the app, choose the source again and restart the conversion.

Remote images and links

Remote content in message bodies is blocked. Web and email links open in your browser or email app when you choose them.

Report a problem

Include your device, system version, app version, the mailbox file type and size, what you tried, and the error message. Describe the mailbox rather than attaching personal mail. If an example is needed, use fictional messages or a copy you have checked for sensitive content.
