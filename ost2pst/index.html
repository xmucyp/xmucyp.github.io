OST to PST

Read your mailbox. Create a PST copy.

OST to PST opens OST and PST mailbox files on Mac, iPhone and iPad. Read available message bodies, preview supported file attachments, and create a PST copy without installing Outlook.

Preview first

Browse your mailbox folders and item counts, search folders by name, and inspect message previews.

Convert on your device

Create a new PST while keeping the source mailbox unchanged. Save it to your chosen location on Mac or export it through Files on iPhone and iPad.

Verify the result

Optionally compare the converted file with your source and review any reported differences.

Local processing

No conversion server or app account is required. Remote content in message bodies is blocked.

Requires macOS 14 or later, or iOS/iPadOS 17 or later.
