Help with your DBF files

Read legacy tables, inspect memo fields and move your data into useful formats on Mac, iPhone and iPad.

Open a DBF table

On Mac, choose Open File… or drag a DBF into the app. On iPhone and iPad, use Open File… and the system document picker, or open a compatible file from Files. Use Try demo file on Home to explore the included sample without supplying your own data.

Memo files and sidecars

Keep matching .dbt or .fpt memo files, .shp geometry and .cpg encoding files with the same base name as the .dbf. Select the needed files together or use the attachment control if the system picker has not granted access to a sidecar. A CDX index is not required for browsing; the app does not maintain CDX indexes when you edit.

Search, encoding and deleted records

Use the Table controls to search, filter and sort. If legacy text looks wrong, change the table encoding from its menu or set a fallback encoding in Settings. CPG and language-driver information can help the app select an encoding. Show deleted records reveals rows marked as deleted; Pack permanently removes those rows from the DBF, so keep a backup.

Convert and export with Pro

Choose Export from an open table or SQL result, then select Excel (.xlsx), CSV, TSV, JSON, SQL inserts or PDF. GeoJSON export uses matching shapefile geometry when attached. On Mac, choose a destination in the Save panel and click Export; on iPhone and iPad, save or share the generated copy using system controls. To create a DBF from a spreadsheet, choose Import CSV / Excel. PDF export includes up to 20,000 rows. SQL results are limited to 50,000 rows. XLSX import reads the first worksheet; legacy binary XLS is not supported. Convert an XLS workbook to XLSX or CSV first.

Editing and SQL

Pro allows supported cell edits, record changes and table restructuring. Edits are saved in place; work on a copy of important source files. Field formats and DBF dialects impose editing limits, and dBASE II tables are read-only. SQL runs against an in-memory SQLite workspace and does not directly write SQL changes back to the DBF. The plain-English assistant drafts SQL using an on-device Apple Intelligence model when available or built-in rules otherwise. Review generated queries and results.

Shapefile maps and local viewing

Attach the matching SHP file and open Map. Geometry with geographic-looking coordinates can use Apple Maps by default, which may request map content from Apple. Choose Plain view to render shapes locally. Projected coordinates use the plain geometry view; this app does not perform coordinate-system reprojection. No device-location permission is needed.

Free access, Pro and restoring purchases

Opening, viewing, searching, sorting, map inspection, attaching sidecars and copying individual values are free. Editing, export, SQL and saving imported spreadsheets as DBF require Pro on your own files. Try editing, export and SQL with the demo table before buying. See Plans on Home or the Pro section in Settings opens Weekly and Lifetime options. Weekly is an auto-renewable subscription; Lifetime is a one-time purchase. The current price is shown before purchase. Restore Purchases is on the upgrade screen. Use the Apple Account that owns the purchase and a network connection. Manage or cancel subscriptions in your App Store account settings.

Troubleshooting

If a file will not open, confirm that it contains a supported DBF format rather than only a renamed extension. For missing memo values, check DBT/FPT names and access. For unreadable text, try the correct encoding. If a purchase is unavailable, check the network and retry; do not purchase again just to restore access. If a file is read-only, make a writable copy in a location you control.

Contact support

Email admin@yenpi.com with your device, operating system, app version, file format and steps to reproduce the issue. Send redacted screenshots or non-sensitive sample files where possible; avoid attaching private databases unnecessarily.
